# Project Description

**Project Name:** VIT Bhopal University Hostel Management

**Author:** PRAJAL ROYZADA

VIT Bhopal University Hostel Management is a Python-based desktop application created using Tkinter. It provides a simple graphical interface for maintaining basic student hostel records.

The application allows the user to enter a student's ID, name, course, and room number. After validation, the record is stored in a Python list. Users can view all stored records, delete a record by entering its Student ID, clear the input fields, or exit the application.

The project demonstrates practical use of Python functions, lists, loops, conditional statements, Tkinter GUI components, and message boxes. It is intended as a basic academic project and can be extended in the future with database storage, search functionality, editing records, room availability tracking, and login features.

The current implementation keeps records only in memory, so the data is lost when the application is closed.
