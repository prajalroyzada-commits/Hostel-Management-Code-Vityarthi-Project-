# Problem Statement

## Hostel Management System

Managing student hostel information manually can take time and may make it difficult to find or update records. A simple computer-based system can make basic student record management easier.

The objective of this project is to develop a beginner-friendly **Hostel Management System** using Python and Tkinter. The application provides a graphical interface where basic student hostel information can be entered, displayed, and removed.

The system stores the following information:

- Student ID
- Student Name
- Course
- Room Number

The project focuses on learning Python programming concepts such as functions, lists, loops, conditional statements, Tkinter widgets, and event handling.

## Scope

This project is intended for educational purposes and demonstrates the basic idea of a hostel record management application. It is not intended to represent or replace an official university hostel management system.

## Main Objectives

1. Create a simple graphical user interface.
2. Add student hostel records.
3. Display stored student records.
4. Delete a student record using the Student ID.
5. Provide basic input validation.
6. Practice Python GUI programming using Tkinter.
